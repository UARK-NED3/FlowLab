# FlowLab Source Notebooks

This folder contains the analysis notebooks and small example files used by
FlowLab.

- `combined-flow-loop-ae/`: combined flow-loop, heater-power, and
  acoustic-emission analysis.
- `accelerometer-labview/`: accelerometer analysis for LabVIEW-acquired data.
- `accelerometer-raspberry-pi/`: accelerometer analysis for Raspberry Pi and
  MCC 172 IEPE DAQ HAT data, including a paired flow-loop workflow.
